# JARVIS Setup Guide

## Prerequisites
- Python 3.10+
- Ollama (installed and running locally)
- Node/npm (if extending frontend) or Playwright dependencies

## Installation
1. Clone the repository.
2. Run the install script:
   ```cmd
   scripts\install.bat
   ```
3. Copy `.env.example` to `.env` and fill in credentials.

## Running JARVIS
Run the startup script:
```cmd
scripts\run.bat
```
